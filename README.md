
# Linear Regression from Scratch

## Project Overview

This project implements Linear Regression from scratch using Python and NumPy. It predicts house prices based on house sizes using mathematical and statistical techniques.

## Objectives

- Generate a synthetic housing dataset.
- Understand the relationship between house size and price.
- Implement Linear Regression using the Normal Equation.
- Implement Gradient Descent from scratch.
- Evaluate the model using RMSE and R2 score.
- Visualize actual versus predicted house prices.

## Technologies Used

- Python
- NumPy
- Matplotlib
- Google Colab

## Project Workflow

1. Generate housing data.
2. Visualize the dataset.
3. Split data into training and testing sets.
4. Train the model using the Normal Equation.
5. Predict house prices.
6. Implement Gradient Descent.
7. Evaluate model performance.
8. Compare both training methods.

## Results

The model produces house price predictions using two approaches:
- Normal Equation
- Gradient Descent

Model performance is evaluated using RMSE and R2 score.
